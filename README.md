# 📰 Daily News App

A modern React-based web application that displays the latest technology news using an external API.

---

## 🚀 Features

* 🔍 Search latest tech news
* 📄 Pagination (Next / Prev)
* ⚡ Fast UI with loading state
* 🖼️ Default image fallback
* 📱 Fully responsive design

---

## 🛠️ Tech Stack

* React (Vite)
* Tailwind CSS
* Axios
* GNews API

---

## ⚙️ Installation

1. Clone the repository:

```
git clone https://github.com/your-username/daily-news-react.git
```

2. Navigate to project:

```
cd daily-news-react
```

3. Install dependencies:

```
npm install
```

4. Add your API key:

Create `.env` file:

```
VITE_API_KEY=your_api_key_here
```

5. Run project:

```
npm run dev
```
